# Each command line from the help alone, then with each option added.
# `same` lists the options with which it exits and reports as it
# does alone: accepted. The others are grouped by what they print,
# the option named as {option}. `every other option` of the
# table's list is not valid for the command. No coordinator is running, so a
# command that gets past its options stops where it asks one. A
# command that asks before it checks its options (check run,
# check status) lists them all as same; the transcript tests
# cover those. `daemon` and `setup` get a state directory that is
# a regular file, so that neither starts anything.
