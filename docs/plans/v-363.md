## Changes

Most callers reach items through `hook`'s re-exports, although `ids`, `text` or
`briefing` owns them. Repoint those callers to the owner. The re-exports stay, because
the hook submodules use them.

| Module | Uses through `hook` | Repointed to |
| --- | --- | --- |
| daemon (`index_queries.rs`, `index_worker.rs`, `prepare.rs`, `remote_worker.rs`) | `wire_id`, `user_workspace_id` | `crate::ids` |
| formatter | `wire_id`, `session_label` | `crate::ids`, `crate::text` |
| report, today | `BRIEFING_LIMIT` | `crate::briefing` |
| briefing (`since`, `recent`, `trail`) | `age`, `clean`, `quoted`, `truncate`, `session_label`, `interface_change_text` | `crate::text`; `super::render` for `interface_change_text` |
| install (`install/detect.rs`) | `install_at` | moved (below) |

`install_at` move: cut it, with its doc comment, from `src/hook/workspace.rs` and paste
it into `src/install.rs`. It uses only `install`'s own items and `fs`. `workspace.rs`
keeps `pub use crate::install::install_at;`, so `project_install` and `cli/doctor`'s
`hook::install_at` don't change. `install/detect.rs` calls `super::install_at`. This also
removes the `install -> hook` cycle (hook already names `install::Vendor`).

Left naming `hook`, because each uses the hook contract itself (`Config`, `Reply`,
`Operation`, deny texts, `execute`): antigravity, between_steps, claude_code, codex,
cursor, cli, commit (`guard_hook`), demo and skill. That makes 9, under 10.
