# v-342: finish moving redaction callers off `hook` (#342)

#451 moved the redactor to `src/text/redact.rs`. What is left, per the latest
verification comment on #342: repoint the remaining callers, then drop
`hook`'s re-export of the five names and the `use text::redact;` alias in
`src/lib.rs`, and remove the edges that go with them.

## Changes

Each changed line is a `use` path or a visibility. Nothing else changes.

- `src/store.rs`, `src/daemon.rs`, `src/auto_check.rs`, `src/commit.rs`,
  `src/definitions.rs`, `src/integrate.rs`, `src/landing.rs`,
  `src/test_output.rs`: `crate::hook::{redact, redact_check, redact_command,
  refuse_secret, contains_secret}` becomes `crate::text::redact::…`.
- `src/client.rs`, `src/git.rs`, `src/shell.rs`, `src/hook/prompt.rs`:
  `crate::redact::…` (the lib.rs alias) becomes `crate::text::redact::…`.
- `src/hook.rs`: drop the `pub use crate::text::redact::{…}` block.
  `hook` itself uses only `redact`, through `hook/prompt.rs`.
- `src/lib.rs`: drop `use text::redact;`, and make `mod text` into
  `pub mod text`. `src/text.rs`: `pub(crate) mod redact` becomes `pub mod redact`.
  Two callers outside the library still need these functions:
  `src/cli/check.rs` in the binary uses `contains_secret`, and
  `tests/store.rs` uses `redact_command`. Both used to reach them through
  `langspan::hook::…`, and now use `langspan::text::redact::…`. Only the five
  functions that were already `pub` become public: `text`'s own items stay
  `pub(crate)`. The public surface grows by two `pub mod` lines and shrinks
  by `hook`'s re-export.
- `src/cli/check.rs`, `tests/store.rs`: path change only. The test's
  assertion stays unchanged.

## Ratchets

- These six modules used `hook` only for redaction, so their `edge hook`
  rows go: `auto_check`, `definitions`, `integrate`, `landing`, `store` and
  `test_output`. `commit` keeps its edge because it also uses `Config`,
  `Reply`, `ShellCall` and `REASON_LIMIT`. `daemon` has no row.
- Then run `python3 -I -B scripts/ratchets.py --tighten` for the lowered
  `pub` counts and removed edges, and `--record` for any rise that the
  visibility change forces (`lib.rs`, `text.rs`). Both go in the same commit.

## Order and checks

This is a refactor, so it adds no new test. The existing tests are the check:
1. Repoint the callers, then drop the re-export and the alias. The build
   fails on any caller still left; `rg 'hook::(redact|contains_secret|refuse_secret)|crate::redact\b'` must return nothing.
2. Run `scripts/ratchets.py --check .` before the baseline change to see the
   stale edges reported, then tighten them and run it again.
3. `git diff --color-moved` shows only path lines. Then `cargo fmt`,
   `cargo clippy --workspace --all-targets --locked -- -D warnings`, the lib
   clippy lane, and `cargo nextest run --workspace --locked`.

No wire format, CLI output or golden file changes. `src/hook.rs` is shared
with f-split-hook, which is splitting it. My edit there removes only the
three-line `pub use` block, so whichever branch lands second rebases trivially.
