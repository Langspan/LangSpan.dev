## Where the measure comes from

It has to be the same in every arm, and only the `langspan` arm has a hook
log. Every arm has a stream-json transcript per session, written through
`guard_session`. The measure is computed from three things the run already
keeps, and never from agent text:

- **What was written**: each `Write`, `Edit` and `MultiEdit` `tool_use`
  block's input in the transcript, replayed over the fixture's file to give
  the file's content after the write.
- **Whether it was admitted**: the matching `tool_result` is not `is_error`.
  A write LangSpan's hook (or the host) refused is not admitted.
- **When**: `guard_session` adds one line after each transcript line that
  carries tool results, `{"type": "langspan_bench_clock", "tool_use_ids": [...],
  "monotonic_ns": N}`. The guard already appends its own verdict line, and
  every reader skips unknown types. All sessions run on one machine, so one
  monotonic clock orders them (engineering.md: monotonic for durations).

The stand-in prints no tool calls today. It will print an `assistant`
`tool_use` and a `user` `tool_result` (with `is_error` when refused) for
each edit, in Claude Code's shape, so dry runs exercise the same path.

Definitions, using `oracle.references` and `oracle.required_arguments` (one
owner for "an old-form call" and "the changed signature"):

- **The change**: the changer's first admitted write after which its
  `shelf/dates.py` requires at least `INTERFACE["arity"]` arguments.
- **A stale-name write admitted**: a dependent's admitted write, at or after
  the change, that leaves its file with a `days_left` reference in the old
  form (fewer arguments, or not a plain call).
- **A stale caller**: a dependent's file with such a reference at or after
  the change. **Fixed** at the admitted write that leaves it without one.
- **`fixed_after_s`**: from the change to the last stale caller fixed;
  `null` when no caller was stale or one stays stale at the session's end
  (then counted in `unfixed`).

Record field `stale_callers` (trial level): `status` (`reported`,
`not_applicable` outside `discovered_change` or when the change was not made,
`unknown` when a transcript is missing, the change write is not seen, or a
replayed file differs from the session's committed file, which means a write
went another way, such as Bash), `writes_admitted`, `stale_files`,
`unfixed`, `fixed_after_s`, and `items` (session, path, seconds after the
change, kind). Bumps `SCHEMA_VERSION` 7 to 8. `summarize` adds per group
`stale_writes_admitted` (sum, `null` unless every compared trial is
`reported`), `stale_fixed_after_s` (the per-trial list, as the mission asks
for individual results) and `stale_unfixed_trials`. Read with `.get`, so
the hand-built records in `test_driver.py` need no change.

Repair-round fixes are not counted: the repair section already reports them.
