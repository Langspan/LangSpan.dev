# ADR 0021: No badge in pull requests

**Status:** Not building. Decided 25 November 2026.

## Context

A coordination tool could append its badge to pull requests that agents open.
The capability review of 25 November 2026 ([roadmap](../roadmap.md),
row F9) recommends not building it.

## Decision

LangSpan does not add a badge, link or other text to pull requests, commits
or any other content an agent or person writes.

The reasons: it is promotion, not coordination; it changes the owner's work
without a command the owner ran for that purpose
([engineering practice](../engineering.md)); and LangSpan does not open or
edit pull requests at all.

## Consequences

Row F9 stays unbuilt in the [roadmap](../roadmap.md), with this record as the reason.
